# munduscraft

munduscraft is a packwiz-managed Minecraft modpack. It targets Minecraft 1.21.1; the current loader version is defined in `pack.toml`.

This repository is the source of truth for pack metadata, mod download metadata, config files, and other files needed to build, serve, or export the pack. Generated exports such as `.mrpack` and `.zip` files are build artifacts and are ignored by Git.

## Repository Layout

- `pack.toml` is the main pack manifest: pack name, author, version, Minecraft version, loader version, and index hash.
- `index.toml` is generated by packwiz and records installable pack files plus their hashes.
- `LICENSE` contains the project license.
- Future mod metadata, config, resource pack, shader pack, script, and default config files should be added through the packwiz workflow in [CONTRIBUTING.md](CONTRIBUTING.md).

## Requirements

- `packwiz`
- Git
- Node.js 24 and npm 11 for repository tooling
- A Minecraft launcher or server environment for testing changes
- A Java version suitable for Minecraft 1.21.1 when testing launches

## Common Commands

```sh
packwiz list -v
packwiz refresh
packwiz serve --port 8080
packwiz modrinth export -o munduscraft.mrpack
packwiz curseforge export -o munduscraft.zip --side client
npm run lint
npm run commit
npm run release
```

`npm run release` is manual-only. It reads commits since the latest `v*` tag, bumps the pack version, updates the changelog, refreshes and formats packwiz metadata, creates exports, commits and tags the release, pushes the release commit and tag, and creates a GitHub release.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the human workflow and [AGENTS.md](AGENTS.md) for concise automation guidance.
